# 在设置窗口中添加UI风格选项

## 目标
在设置窗口中添加UI风格选择功能，包括默认、液态玻璃和亚克力三种风格选项。

## 实现步骤

### 1. 修改 SettingsModal.tsx 组件
- 添加UI风格选择部分，包含三个单选选项：默认、液态玻璃、亚克力
- 实现选项的视觉样式和选中状态
- 添加状态管理来跟踪当前选中的UI风格

### 2. 在 App.tsx 中添加UI风格状态管理
- 添加 `uiStyle` 状态变量，默认值为 'default'
- 添加 `setUiStyle` 函数来更新UI风格
- 将 `uiStyle` 和 `setUiStyle` 传递给 SettingsModal 组件

### 3. 实现UI风格切换逻辑
- 在 SettingsModal 中添加处理UI风格选择的函数
- 确保每次只能选择一个选项
- 实现默认选中默认风格的逻辑

### 4. 应用UI风格样式
- 根据选中的UI风格，为应用中的元素应用相应的样式
- 实现液态玻璃效果（iOS 26风格）：16.5%透明白色背景、淡蓝色阴影、多层白色内阴影、10px增强模糊、半透明边框
- 实现亚克力效果（Windows 11风格）：69%透明白色背景、20px模糊、无边框、黑色外阴影
- 实现默认风格（当前样式）：保持现有的白色背景和阴影效果

## 技术实现细节

### 液态玻璃模式样式
```css
background: #FFFFFF2A; /* 16.5% 透明度白色 */
border: 1px solid #FFFFFF33; /* 20% 透明度白色边框 */
backdrop-filter: blur(10px) saturate(1.35); /* 较浅模糊 + 饱和度增强 */
box-shadow:
  0 8px 24px #20268833, /* 主阴影：淡蓝色（20%透明度） */
  inset 0px 0px 10px #FFFFFF1A, /* 内发光：白色（10%透明度） */
  inset -3px 3px 4px #FFFFFF10, /* 内阴影：白色（6%透明度） */
  inset -0.5px 0.5px 0px #FFFFFF60; /* 高光边缘：白色（37.5%透明度） */
```

### 亚克力模式样式
```css
background: #FFFFFFB0; /* 69% 透明度白色 */
border: none; /* 无边框 */
backdrop-filter: blur(20px); /* 中度模糊 */
box-shadow: 0px 2px 12px rgba(0,0,0,.1); /* 简洁的黑色阴影 */
```

### 默认模式样式
保持现有的白色背景和阴影效果。
