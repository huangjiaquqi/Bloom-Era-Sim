# 游戏属性分类总结

## 一、通用属性（基础核心属性）
| 属性名 | 作用描述 |
|--------|----------|
| 心态 | 影响情绪状态、承受压力能力 |
| 经验 | 影响成长速度、理解能力 |
| 运气 | 影响随机事件概率、捡钱概率 |
| 魅力 | 影响人际关系、恋爱成功概率 |
| 健康 | 影响生病概率、生存状态 |
| 金钱 | 购买道具、参与活动 |
| 效率 | 学习效果、属性提升倍率 |

## 四、学生属性（综合能力与状态）

|--------|----------|
| 思维能力 | 决定解题思路的形成能力 |
| 编码能力 | 决定代码实现的速度和准确性 |
| 心理素质 | 影响比赛发挥的稳定性 |

### 知识结构
| 属性名 | 作用描述 |
|--------|----------|
| 数据结构知识 | 数据结构相关题目得分 |
| 图论知识 | 图论相关题目得分 |
| 字符串知识 | 字符串相关题目得分 |
| 数学知识 | 数学相关题目得分 |
| 动态规划知识 | 动态规划相关题目得分 |

### 状态属性
| 属性名 | 作用描述 |
|--------|----------|
| 压力值 | 过高会降低效率、增加退队风险 |
| 舒适度 | 影响压力恢复速度 |
| 生病周数 | 生病时训练效率大幅降低 |

### 其他属性

|--------|----------|
| 天赋集合 | 学生拥有的天赋 |
| 倦怠周数 | 连续高压的周数 |
| 抑郁次数 | 抑郁状态累计次数 |
| 高压周数 | 压力过高的周数 |

## 五、能力属性（综合操作与表现）
| 属性名 | 作用描述 |
|--------|----------|
| thinking | 思维，影响思考成功率 |
| coding | 代码，减少写代码时间 |
| carefulness | 细心，增加成功率，降低出错率 |
| experience | 经验，增加查看模糊题目属性的概率 |
| quickness | 迅捷，减少思考时间 |
| mental | 心理素质，减少心态下降 |
| culture | 文化课 |
| determination | 决心，用于商店购买 |
| mood | 心态，影响所有操作成功率（0-32） |

## 属性归类总结

### 1. 状态类属性
- 心态、健康、压力值、舒适度、生病周数、倦怠周数、抑郁次数、高压周数、mood

### 2. 能力类属性
- 经验、效率、思维能力、编码能力、thinking、coding、carefulness、quickness、determination

### 3. 知识/学科类属性
- 所有学科属性、OI竞赛属性、知识结构属性、算法细分属性

### 4. 社交/资源类属性
- 魅力、金钱、运气

### 5. 心理/素质类属性
- 心理素质、mental、experience

### 6. 综合类属性
- 天赋集合、culture

## 说明
这些属性覆盖了游戏的多个维度：个人成长、学业表现、竞赛能力、心理状态、社交关系等，构成了一个完整的游戏属性体系。
